# Skill Radar

A quick skills quiz for our team at the NASA Space Apps Challenge 2026 (Singapore). Each member answers 18 questions and gets a radar chart of their strengths across 8 areas, so we can split the hackathon work based on what everyone is good at and enjoys.

## Features
- Slide-based quiz with progress bar
- Personal radar chart with chosen color, preferred area and availability
- Team dashboard that updates live: overview radar, individual maps, top 3 per area and availability
- Export one or all results as an image (for Telegram) or as text
- Retaking the quiz with the same name replaces your previous answers

## Areas
Backend & data engineering · Frontend & web dev · Data analysis & statistics · Earth science & remote sensing · AI / ML · UI/UX & visual design · Storytelling, pitch & docs · Leadership & teamwork

## Stack
Plain HTML, CSS and JavaScript on GitHub Pages, with Supabase for storing responses.
