# Skill Radar

**Live:** https://davidserret.github.io/skill-radar/

A quick skills quiz for our team at the NASA Space Apps Challenge 2026 (Singapore). Each member answers 20 scored questions and gets a radar chart of their strengths across 9 areas, so we can split the hackathon work based on what everyone is good at and enjoys.

## Features
- Slide-based quiz with progress bar
- Availability per day, meeting availability and briefing attendance
- Ranked task preferences (up to 4, with a custom "Other" option)
- Personal radar chart with chosen color, top task and availability
- Team dashboard that updates live: individual maps, top 3 per area, comparison radar and availability
- Export cards, rankings and availability as an image (for Telegram) or as text
- Retaking the quiz with the same name replaces your previous answers

## Areas
Backend & data engineering · Frontend & web dev · Data analysis & statistics · Earth science & remote sensing · AI / ML · Rapid prototyping · UI/UX & visual design · Storytelling, pitch & docs · Leadership & teamwork

## Stack
Plain HTML, CSS and JavaScript on GitHub Pages, with Supabase for storing responses.
